# GONKI — 3D-гонки без правил

Браузерная 3D-гонка на [Three.js](https://threejs.org/) с реалистичной физикой
машин на базе [cannon-es](https://github.com/pmndrs/cannon-es). Полный контактный
режим: можно таранить и сбивать соперников, машины реалистично сталкиваются.

## Возможности

- 3D-графика: трасса с барьерами, разметкой, деревьями, динамические тени.
- Реалистичная физика автомобиля (raycast vehicle): подвеска, сцепление, занос.
- Контактные столкновения машина-машина и машина-барьер (тарань соперников).
- 3 ИИ-соперника со своими характерами (скорость, агрессия).
- Гоночный режим: 3 круга, позиция в гонке, таймер, лучший круг.
- HUD: спидометр, позиция, круг, время, мини-карта с машинами.
- 3 режима камеры (преследование / дальняя / из капота).

## Управление

| Клавиша | Действие |
| --- | --- |
| `W` / `↑` | газ |
| `S` / `↓` | тормоз / задний ход |
| `A` `D` / `←` `→` | руль |
| `Space` | ручник (занос) |
| `R` | перевернуть машину обратно |
| `C` | сменить камеру |

## Разработка

```bash
npm install
npm run dev      # запустить дев-сервер (http://localhost:5173)
npm run build    # собрать продакшн-сборку в dist/
npm run preview  # предпросмотр продакшн-сборки
```

## Стек

- **Three.js** — рендеринг 3D-сцены.
- **cannon-es** — физический движок (RaycastVehicle).
- **Vite** — сборка и дев-сервер.
